# Fishing Frog

Projeto criado para diciplina de python durante a faculdade de Engenharia de Software na Uninter.

## Gameplay
É só esperar o tempo passar enquanto escuta uma musiquinha relaxante, quando o momento chegar você poderá pescar um peixinho e exibir na sua lista de peixinhos pescados :3

## Para jogar:
Eu desenvolvi ele no pycharm, se colocar o código do projeto lá da pra rodar certinho.

Eu também adicionei o jogo compilado na pasta FishingFrogExe, ele ta misturado com o código mas é possível baixar apenas os arquivos do jogo na branch [the-game](https://github.com/ElizaWbr/fishing-frog/tree/1f3e23a3869eeb771175234cc43de4df81736084/FishingFrogExe/asset).

Depois de baixar e extrair é só rodar o main.exe, seu computador vai reclamar então está por sua conta e risco.

É só um projeto fofo, eu juro :)

### Controles
- Espaço para selecionar e pescar;
- Setinhas para mover para cima e para baixo;
- Backspace para voltar;
